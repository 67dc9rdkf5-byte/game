# AI Game Studio Foundation

Модульный шаблон игровой студии для разработки и публикации HTML5-игр на платформе **Яндекс Игры**.

В комплекте уже работает демонстрационная 2D-аркада **Vector Pulse** с полностью подключёнными системами рекламы, сохранений, звука, аналитики и адаптивного управления для ПК, планшетов и смартфонов.

---

## Состав проекта

- **Phaser 3 + TypeScript + Vite** — игровой движок, строгая типизация и быстрая сборка.
- **YandexSDK и PlatformAdapter** (`src/platform/`) — официальная интеграция с `/sdk.js` (`YaGames.init()`, `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, события паузы и возобновления платформы) и безопасный локальный режим для разработки без начисления фиктивных наград.
- **AdsManager** (`src/systems/AdsManager.ts`) — централизованное управление Fullscreen-рекламой, Rewarded Video и Sticky Banner с блокировкой геймплея на время показа.
- **SaveManager** (`src/systems/SaveManager.ts`) — локальное хранение рекордов, прогресса, кристаллов, достижений и настроек звука с проверкой повреждённых сохранений и заготовкой под облачные сохранения Яндекс Игр.
- **AudioManager** (`src/systems/AudioManager.ts`) — встроенный синтез музыки и эффектов на Web Audio API, снятие блокировки автовоспроизведения браузера и раздельная регулировка громкости.
- **AnalyticsManager** (`src/systems/AnalyticsManager.ts`) — система событий (`game_started`, `game_paused`, `game_resumed`, `level_completed`, `game_over`, `rewarded_ad_requested`, `rewarded_ad_completed`, `fullscreen_ad_requested`) без передачи персональных данных.

## Быстрый запуск для проверки

1. Установите зависимости (выполняется один раз после скачивания проекта):
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте игру в браузере по адресу, который появится в терминале (по умолчанию `http://localhost:3000`).

> **Важно про локальный режим:** вне сайта Яндекс Игр файл `/sdk.js` отсутствует, поэтому автоматически включается безопасный локальный режим. В этом режиме игра работает полностью, но реклама не имитируется и фиктивные награды за просмотр видео не выдаются.

## Проверка кода и сборка

Проверка типов TypeScript:
```bash
npm run lint
```

Сборка готовой игры для публикации:
```bash
npm run build
```

После выполнения `npm run build` готовая игра появится в папке **`dist/`** с относительными путями (`./assets/...`). Исходный код (`src/`) и зависимости (`node_modules/`) в папку `dist/` не попадают.

## Подготовка ZIP-архива для Яндекс Игр

Платформа Яндекс Игры требует, чтобы файл `index.html` находился **в самом корне ZIP-архива**, а не внутри вложенной папки `dist/`.

### Вариант 1: Через терминал (Linux / macOS)

```bash
npm run build
cd dist
zip -r ../yandex-game-build.zip .
cd ..
```

### Вариант 2: Вручную в Windows / macOS

1. Выполните `npm run build`.
2. Откройте папку `dist` (зайдите **внутрь** неё).
3. Выделите все файлы и папки внутри `dist` (`index.html`, `favicon.png`, `assets/`).
4. Нажмите правой кнопкой мыши и выберите **«Сжать в ZIP-файл»** (или *«Отправить → Сжатая ZIP-папка»*).
5. Проверьте, что при открытии созданного архива сразу видны `index.html` и папка `assets/`, а не папка `dist/`.

## Чек-лист перед отправкой на модерацию

- Выполнена команда `npm run build` без ошибок.
- В корне ZIP-архива лежит `index.html`.
- Внутри `index.html` подключён `<script src="/sdk.js"></script>`.
- Полноэкранная реклама не появляется во время активного управления персонажем.
- Награда за видео выдаётся только после подтверждения просмотра (`onRewarded`).
- Игра корректно ставится на паузу и отключает звук при сворачивании вкладки или открытии рекламы.
- Интерфейс не обрезается в портретной и альбомной ориентации экрана.
